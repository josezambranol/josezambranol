## 👨‍💻 Sobre mí

Desarrollador enfocado en **Backend con Java (17/21) y Spring Boot 3**, construcción de **APIs REST seguras**, bases de datos relacionales/NoSQL y contenerización con **Docker**. Me gusta aprender construyendo productos reales con pruebas automatizadas e integración continua.

- 🛡️ **Seguridad y Calidad:** Spring Security 6, JWT, RBAC, Bucket4j, sanitización XSS, JUnit 5, Mockito, Testcontainers y Playwright.
- ⚡ **Flujo de Ingeniería & Productividad:** Diseño la arquitectura y lógica de negocio desde las bases, apoyándome en herramientas de IA como **Claude** y **Antigravity** para acelerar pruebas, refactorizaciones, automatizaciones y revisión técnica.
- 🤖 **En progreso:** Automatizaciones de procesos, scripts de productividad e infraestructura con Python, Java y CI/CD.
