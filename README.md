## 👨‍💻 Sobre mí

Estudiante de **Tecnología en Desarrollo de Software** (5.º semestre) en el **Tecnológico Comfenalco**. Me enfoco en el desarrollo de soluciones robustas con **Java** y **Spring Boot**, diseño de aplicaciones de escritorio interactivas con **TypeScript / Electron**, y la integración de **Inteligencia Artificial** (Google Gemini) para crear experiencias de software modernas y de alto valor.

- 🎯 **Objetivo:** Continuar creando proyectos escalables, explorando nuevas tecnologías y aportando soluciones de calidad técnica.

## 🚀 Proyectos Destacados

### 🌴 1. [Odyssey — Plataforma Turística & Asistente IA](https://github.com/josezambranol/Odyssey)
> **Ecosistema web turístico bilingüe con Asistente Inteligente impulsado por Google Gemini para Cartagena de Indias.**

- 🧠 **IA Integrada:** Chatbot virtual contextualizado con **Google Gemini 2.5 Flash** (historia, gastronomía, clima y eventos) con motor de fallback local por palabras clave.
- 🎟️ **Cartelera Cultural en Vivo:** Sincronización dinámica de festivales y eventos culturales con API REST pública (`/api/eventos`).
- 🛡️ **Seguridad y Roles:** Implementación de **Spring Security 6** con modelo *Open Access* para consultas y *RBAC* con contraseñas cifradas en **BCrypt** para reseñas y administración.
- 📦 **Stack:** `Java 21 LTS` · `Spring Boot 3.2` · `Spring Security 6` · `MySQL` · `Thymeleaf` · `Bootstrap 5` · `Google Gemini AI` · `Maven`.

---

### 👾 2. [PixelVibe — 8-Bit Retro Spotify Player & Companion](https://github.com/josezambranol/PixelVibe)
> **Reproductor de escritorio para Spotify con estética retro 8-bit, karaoke sincronizado en tiempo real y personaje interactivo en pantalla.**

- 🎤 **Karaoke Engine de Alta Precisión:** Parser LRC con compensación matemática de latencia de red (RTT) y anticipación fonética de +180ms para sincronización milimétrica con [LRCLIB](https://lrclib.net).
- 🥷 **Companion Flotante:** Personaje animado anclado a la barra de tareas de Windows con máquina de estados de ánimo (*dancing, sleeping, greeting, scolding*) y burbujas de diálogo con letras sincronizadas.
- 🎚️ **Visualizador de Audio & Temas Dinámicos:** Renderizado en Canvas 2D, ecualizador retro, cuantizador de portada para paletas de color y sincronización de hardware con **OpenRGB SDK**.
- 🔒 **Seguridad Desktop:** Cifrado seguro a nivel de SO con **DPAPI (Electron safeStorage)** y autenticación **OAuth 2.0 PKCE**.
- 📦 **Stack:** `TypeScript 5.7` · `Electron 34.2` · `Vite 6.1` · `Spotify Web API` · `Canvas 2D API` · `PowerShell Interop`.

---

### 🤖 3. [MiniJefe — Bot Académico & Control de Horarios 24/7](https://github.com/josezambranol/minijefe-discord-bot)
> **Bot interactivo de Discord para la gestión universitaria, seguimiento estricto de entregas y recordatorios automáticos de clases.**

- 🎓 **Control de Clases en Tiempo Real:** Avisos automáticos 30 minutos antes de cada clase universitaria en Cedesarrollo, indicando salón, materia y docente.
- 📝 **Parser NLP en Español:** Procesamiento de lenguaje natural para fechas de entrega (`"mañana 6:30 pm"`, `"en 3 dias"`, `"hoy 8:00 pm"`).
- ⚡ **UI Interactiva:** Formularios Modales para creación de tareas y botoneras de 1-clic (*Completar, Posponer, Eliminar*).
- ☁️ **Despliegue Continuo 24/7:** Alojado en **Render.com** con servidor de salud interno y monitoreo constante con **UptimeRobot**.
- 📦 **Stack:** `Python 3.12+` · `Discord.py v2.7` · `aiosqlite (SQLite Asíncrono)` · `Render` · `UptimeRobot`.

---

### 🛒 4. [Tienda API — API REST Comercial](https://github.com/josezambranol/tienda-api)
> **API REST robusta para la gestión integral de inventario, clientes y ventas con descuento atómico de stock.**

- 💳 **Transaccionalidad Atómica:** Control concurrente de inventario para garantizar consistencia en cada venta.
- 🗄️ **Persistencia:** Configuración optimizada con **Spring Data JPA** y almacenamiento en disco con **H2**.
- 📦 **Stack:** `Java 17` · `Spring Boot` · `Spring Data JPA` · `H2 Database` · `Lombok` · `REST API`.

### 🚛 5. [XYZ API — Gestión de Flota y Conductores](https://github.com/josezambranol/xyz-api)
> **API REST para la administración de vehículos de transporte y asignación de conductores con control de acceso por roles.**

- 🔐 **Spring Security & Basic Auth:** Autenticación estricta con roles diferenciados (`ADMIN` para creación, `SUPERVISOR` para asignación).
- 📦 **Stack:** `Java 21` · `Spring Boot` · `Spring Security 6` · `Spring Data JPA` · `H2 Database` · `Maven`.
