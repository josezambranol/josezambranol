## 👨‍💻 Sobre mí

Estudiante de **Tecnología en Desarrollo de Software** en el **Tecnológico Comfenalco**. Me enfoco en el desarrollo de soluciones sólidas, escalables y con altos estándares de seguridad. Cuento con experiencia práctica en arquitectura backend con **Java** y **Spring Boot 3**, microservicios y observabilidad, herramientas forenses y automatización con **Python (FastAPI)**, aplicaciones de escritorio interactivas con **TypeScript / Electron**, y la integración de **Inteligencia Artificial** (Google Gemini) para diseñar productos digitales modernos y eficientes.

- 🎓 **Formación:** Tecnología en Desarrollo de Software (TDS) — Tecnológico Comfenalco.
- 💡 **Metodología y Filosofía de Trabajo:** Diseño y programo soluciones **de forma manual, modular y estructurada**, definiendo la arquitectura, patrones de diseño y buenas prácticas (**OWASP Top 10, Clean Architecture**) desde las bases, y utilizando la **Inteligencia Artificial** como copiloto técnico para optimizar código, depurar algoritmos complejos, fortalecer pruebas automatizadas y elevar la calidad de entrega.
- ⚡ **Experiencia práctica:** Plataformas web con arquitectura segura y rate limiting, suites forenses de recuperación multimedia, ecosistemas turísticos con IA generativa, microservicios distribuidos con métricas de salud en tiempo real, bots de productividad en la nube y aplicaciones de escritorio con integración de hardware.
- 🎯 **Objetivo:** Continuar diseñando software de alta confiabilidad y rendimiento, dominando el ecosistema cloud-native y aportando soluciones de impacto técnico y social.

## 🚀 Proyectos Destacados

### 💈 1. [Barbería Elites — Plataforma Web con Arquitectura Segura & OWASP](https://github.com/josezambranol/barberia-segura)
> **Plataforma web de producción para agendamiento y gestión de barbería diseñada bajo principios de seguridad OWASP Top 10.**

- 🛡️ **Seguridad Defensiva & OWASP:** Rate limiting granular con **Bucket4j** (anti-fuerza bruta y anti-spam), sanitización XSS con **Jsoup**, validación estricta de imágenes por **Magic Bytes binarios** y cabeceras HTTP reforzadas (HSTS, CSP, no-sniff).
- 🔑 **Acceso Cero Fricción & JWT:** Reservas públicas mediante **Token Único Criptográfico (`UUID v4`)** sin obligar al cliente a crear cuenta; y portal administrativo para staff protegido con **Spring Security 6 + JWT rotativo** (Access & Refresh tokens en BD).
- 🗄️ **Persistencia & Despliegue:** Base de datos **PostgreSQL 16** versionada con migraciones automáticas en **Flyway**, gestión de imágenes en la nube con **Cloudinary** y orquestación con **Docker Compose**.
- 📦 **Stack:** `Java 21` · `Spring Boot 3` · `Spring Security 6` · `PostgreSQL` · `Flyway` · `Docker` · `Bucket4j` · `Cloudinary` · `OpenAPI/Swagger`.

### 🔬 2. [Universal Recovery Pro — Suite Forense de Recuperación Multimedia](https://github.com/josezambranol/UniversalRecoveryPro)
> **Suite de escritorio y aplicación web forense para la recuperación profunda de archivos multimedia en Android, iOS y discos corruptos.**

- 🔬 **Motor de File Carving:** Extracción directa byte a byte mediante firmas binarias (*Magic Bytes*) para formatos JPEG, PNG, WebP y HEIC/AVIF sin depender de que el sistema de archivos esté intacto.
- 📱 **Forense Móvil (Android & iOS):** Análisis de bases de datos residuales (`Photos.sqlite`), catálogos de respaldo iTunes (`Manifest.db`), miniaturas huérfanas (`.thumbnails`), papelera oculta de Android y sincronización con iCloud (2FA).
- 🎨 **Interfaz Híbrida & Alta Usabilidad:** SPA moderna construida con **FastAPI** y **Tailwind CSS** (Glassmorphism), visor Lightbox con metadatos EXIF y modos alternativos para GUI de escritorio (Tkinter) o línea de comandos (CLI).
- 🧪 **Testing Automatizado:** Suite integral de pruebas unitarias y de validación forense (`test_full_suite.py`).
- 📦 **Stack:** `Python 3.10+` · `FastAPI` · `Tailwind CSS` · `SQLite` · `Pillow` · `ADB` · `Tkinter`.

> **Ecosistema web turístico bilingüe con Asistente Inteligente impulsado por Google Gemini para Cartagena de Indias.**

### 👾 4. [PixelVibe — 8-Bit Retro Spotify Player & Companion](https://github.com/josezambranol/PixelVibe)
> **Reproductor de escritorio para Spotify con estética retro 8-bit, karaoke sincronizado en tiempo real y companion interactivo en pantalla.**

- 🎤 **Karaoke Engine de Alta Precisión:** Parser LRC con compensación matemática de latencia de red (RTT) y anticipación fonética de +180ms para sincronización milimétrica con [LRCLIB](https://lrclib.net).
- 🥷 **Companion Flotante:** Mascota animada anclada a la barra de tareas de Windows con máquina de estados de ánimo (*dancing, sleeping, greeting, scolding*) y globos de diálogo con letras sincronizadas.
- 🎚️ **Visualizador de Audio & RGB Dinámico:** Renderizado en Canvas 2D, ecualizador retro, cuantizador de portada para paletas dinámicas y sincronización de iluminación de hardware vía **OpenRGB SDK**.
- 🔒 **Seguridad Desktop:** Cifrado nativo a nivel de sistema operativo con **DPAPI (Electron safeStorage)** y autenticación segura **OAuth 2.0 PKCE**.
- 📦 **Stack:** `TypeScript 5.7` · `Electron` · `Vite` · `Spotify Web API` · `Canvas 2D API` · `OpenRGB SDK`.
